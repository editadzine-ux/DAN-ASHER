# העברה לאלמנטור דרך Novamira

## בקצרה: כן, אפשר

האתר המחובר (ZIMMER) מריץ WordPress 7.1.3, Elementor 4.3.4 + Elementor Pro 4.3.1, Novamira Pro ותבנית Hello Elementor Child.
ב־Novamira Pro יש מיומנות ייעודית לכך, `elementor-build-page`, שבונה עמוד אלמנטור ממקור HTML. בנוסף יש לה גישה לקבצי ה־child theme ולספריית המדיה.

"בדיוק כפי שהוא" תלוי בדרך שבוחרים:

| דרך | נאמנות לעיצוב | עריכה באלמנטור | הערות |
|---|---|---|---|
| **א. HTML מלא בתוך אלמנטור** (ווידג'ט HTML או Custom Code, CSS ו־JS ב־child theme) | 100%, כולל כל האנימציות | נמוכה. עורכים טקסט בקוד, לא בגרירה | הכי מהיר והכי מדויק |
| **ב. בנייה מחדש בווידג'טים מקוריים** (Containers, Heading, Text, Button, Image, Accordion, Tabs) | בערך 90–95% | מלאה | הבצל, העין המונפשת ומסע הידע לא קיימים כווידג'טים, והאנימציות המותאמות יאבדו |
| **ג. היברידי (מומלץ)** | בערך 98–100% | גבוהה לכל הטקסטים | סקשנים של טקסט, כרטיסים, FAQ, שירותים ואודות בווידג'טים מקוריים. הירו, בצל, מסע הידע ואייקוני התהליך בווידג'טי HTML. CSS גלובלי ב־child theme |

## דברים שחייבים לטפל בהם בכל דרך

1. **כיוון השפה.** האתר מוגדר בעברית (he_IL, ימין־לשמאל) והעמוד באנגלית. צריך לעטוף את העמוד ב־`dir="ltr" lang="en"`, אחרת הפריסה תתהפך.
2. **תבנית עמוד.** להשתמש ב־Elementor Canvas, כדי שההדר והפוטר של העמוד יחליפו את אלה של התבנית. אפשרות אחרת: לבנות אותם ב־Theme Builder.
3. **תמונות.** להעלות את `assets/` לספריית המדיה ולעדכן את הנתיבים.
4. **פונטים.** Google Fonts. כדאי לארח אותם מקומית דרך Elementor (Local Google Fonts), בגלל תוסף ניהול ההסכמה לפרטיות שמותקן באתר.
5. **הדר דביק ותפריט תוכניות דביק.** קונטיינרים של אלמנטור שמוגדר להם `overflow:hidden` שוברים את `position:sticky`. צריך לבטל את זה על הקונטיינרים העוטפים. כשמשתמש מחובר, יש לקחת בחשבון גם את גובה פס הניהול של וורדפרס.
6. **JavaScript.** הסקריפט בסוף `index.html` עצמאי ולא נשען על ספריות. הוא נטען דרך Elementor Custom Code או דרך `wp_enqueue_script` ב־child theme.
7. **תוסף הנגישות** שמותקן באתר מוסיף ווידג'ט צף, וצריך לבדוק שהוא לא מסתיר את כפתורי הבצל במובייל.

## השלב הבא

כשתאשרי איזו דרך מתאימה ובאיזה עמוד באתר לעבוד (עמוד חדש או קיים), אפשר לבצע את ההעברה ישירות דרך Novamira.
